# Вёрстка «Премиальные гриль-кухни»

Статическая страница на HTML, CSS и обычном JavaScript, без сборки и сторонних UI-библиотек. Основа — экран `174:4806 / 1920 Main` файла Figma и исходный `Untitled.fig`. Использованы оригинальные изображения, тексты, цвета и структура страницы. Адаптивная компоновка учитывает версии 1440, 768 и 320 из файла.

## Как открыть

Распакуйте архив целиком и откройте `index.html` в браузере. Не перемещайте HTML отдельно от остальных файлов. Для размещения на хостинге загрузите содержимое папки в каталог сайта.

Можно запустить локальный сервер из этой папки:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Файлы

- `index.html` — семантическая разметка страницы.
- `styles.css` — оформление и адаптивные правила.
- `fonts.css` — локальный Montserrat.
- `script.js` — меню, модальные окна, этапы, слайдеры, FAQ, формы, сохранение параметров.
- `data.js` — тексты интерактивных блоков из макета.
- `config.js` — контакты и точки подключения сайта.
- `assets/` — исходные изображения, SVG и локальные шрифты. Временных ссылок Figma в рабочем коде нет.

## Что работает

Фиксированная шапка и якорная навигация; мобильное меню; подробности карточек в модальных окнах; четыре этапа работ; выбор параметров кухни; окно результатов и скачивание параметров в TXT; галерея с переключением изображений и свайпом; прокрутка отзывов и брендов; раскрытие только одного вопроса одновременно; формы с валидацией телефона; модальные окна с закрытием по Escape и возвратом фокуса. Переключатели этапов поддерживают клавиши стрелок, Home и End.

## Что подключить в config.js

1. `phone`, `telegramUrl`, `whatsappUrl` — настоящие контакты. Телефон `+7 333 333 33 33` сохранён из макета как текстовая заглушка; звонок на него не запускается.
2. `formEndpoint` — серверный обработчик заявки. POST JSON: `{ "name": "...", "phone": "...", "channel": "Звонок" }`. Успешный HTTP 2xx означает принятие заявки. Если адрес не задан, страница честно сообщает, что заявка не отправлена. Обработчик должен проверять входные данные и ограничивать спам; секретные ключи размещаются только на сервере.
3. `calculatePrice` — функция расчёта по утверждённому прайсу. Получает `{material, placement, size, configuration}` и возвращает число в рублях. Формулы и цены в исходных данных не заданы: сейчас сохраняются выбранные параметры без произвольной стоимости. Эскизы и коммерческое предложение для каждой комбинации не генерируются.
4. `videoUrl` — MP4/WebM или ссылка на embed-плеер. В макете есть обложка, а файла видео нет.
5. `privacyUrl`, `termsUrl`, `offerUrl` — ссылки на готовые документы.

## Отличия и ограничения

В макете заголовки набраны Posterama Text. Файл `.fig` не включает сам шрифт; пока используется Montserrat, поэтому начертание и отдельные переносы отличаются. Для точного совпадения предоставьте лицензированные веб-файлы Posterama Text SemiBold (600) и Bold (700), добавьте `@font-face` в `fonts.css` и установите для `h2` вес 700. Имя семейства в CSS уже настроено на `Posterama Text` с запасным Montserrat.

Модальные окна выполнены в общем стиле страницы; их полное совпадение со всеми отдельными прототипами не заявляется. Мобильная версия адаптирована по структуре исходника, без дублирующих старых блоков. Отзывы и номер телефона в макете выглядят как демонстрационные — тексты сохранены, новые отзывы не придуманы. В исходных текстах различаются сроки: в этапах 30 дней, в FAQ 1–2 месяца; перед публикацией согласуйте единый срок.

## Проверка

Проверены ширины 1920, 1440, 768, 390 и 320 px: горизонтального переполнения страницы нет. Проверены загрузка локальных изображений и шрифтов, отсутствие ошибок JavaScript и основные интерактивные сценарии. Серверная отправка заявок и настоящий расчёт не проверялись, поскольку их обработчики не подключены.
